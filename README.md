# Adaptive Quant Framework

## Overview

Adaptive Quant Framework (AQF) es una plataforma de trading algorítmico profesional desarrollada para MetaTrader 5.

El objetivo del proyecto es crear un framework reutilizable que permita implementar múltiples estrategias cuantitativas utilizando un mismo núcleo de gestión del riesgo y análisis del mercado.

La primera estrategia desarrollada será:

**AQF XAU Scalper**
